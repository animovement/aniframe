# Arrange rows of an aniframe

Arrange rows of an aniframe

## Usage

``` r
# S3 method for class 'aniframe'
arrange(.data, ..., .by_group = FALSE)
```

## Arguments

- .data:

  An aniframe object

- ...:

  Variables to order by

- .by_group:

  If TRUE, arrange within groups

## Value

An arranged aniframe
