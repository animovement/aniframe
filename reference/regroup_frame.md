# Group a frame by the given columns, or ungroup it when there are none

Group a frame by the given columns, or ungroup it when there are none

## Usage

``` r
regroup_frame(data, grouping_vars)
```

## Arguments

- data:

  A plain (non-animovement) data frame.

- grouping_vars:

  Character vector of columns to group by.

## Value

`data`, grouped or ungrouped.
