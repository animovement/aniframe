# Is this a usable map of axis roles to directions?

Is this a usable map of axis roles to directions?

## Usage

``` r
ensure_valid_axis_directions(directions)
```

## Arguments

- directions:

  Value supplied to
  [`set_axis_directions()`](https://animovement.dev/anicore/reference/set_axis_directions.md).

## Value

`TRUE`, invisibly.
