# Is this a named map keyed by axis role?

Is this a named map keyed by axis role?

## Usage

``` r
ensure_named_axis_map(x, arg, example, call = rlang::caller_env())
```

## Arguments

- x:

  Value to test.

- arg:

  Name of the argument it came from.

- example:

  A well-formed value, shown when `x` is not one.

## Value

`TRUE`, invisibly.
