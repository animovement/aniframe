# Arrange rows of an anievent

Arrange rows of an anievent

## Usage

``` r
# S3 method for class 'anievent'
arrange(.data, ..., .by_group = FALSE)
```

## Arguments

- .data:

  An anievent object.

- ...:

  Variables to order by.

- .by_group:

  If TRUE, arrange within groups.

## Value

An arranged anievent.
