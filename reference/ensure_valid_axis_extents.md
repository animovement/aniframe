# Is this a usable map of axis roles to extents?

Is this a usable map of axis roles to extents?

## Usage

``` r
ensure_valid_axis_extents(extents)
```

## Arguments

- extents:

  Value supplied to
  [`set_axis_extents()`](https://animovement.dev/anicore/reference/set_axis_extents.md).

## Value

`TRUE`, invisibly.
