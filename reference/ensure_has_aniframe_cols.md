# Validate required columns for aniframe

Validate required columns for aniframe

## Usage

``` r
ensure_has_aniframe_cols(
  data,
  variables_what,
  variables_when,
  variables_where,
  index = "time"
)
```

## Arguments

- data:

  Data frame to validate.

- variables_what:

  Identity variables.

- variables_when:

  Temporal variables.

- variables_where:

  Spatial variables.
