# Slice rows from an anievent

Slice rows from an anievent

## Usage

``` r
# S3 method for class 'anievent'
slice(.data, ..., .preserve = FALSE)
```

## Arguments

- .data:

  An anievent object.

- ...:

  Integer row positions.

- .preserve:

  Keep group structure.

## Value

A sliced anievent.
