# Each direction as a unit vector

In a right-handed basis with `right`, `up` and `back` as the positive
axes — `back` being toward the viewer.
[`get_angle_direction()`](https://animovement.dev/anicore/reference/get_angle_direction.md)
and
[`get_handedness()`](https://animovement.dev/anicore/reference/get_handedness.md)
are read off these.

## Usage

``` r
list_direction_vectors()
```

## Value

Named list of length-3 numeric vectors.
