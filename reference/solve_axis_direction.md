# Find the direction of one axis from the answer the whole set should give

Find the direction of one axis from the answer the whole set should give

## Usage

``` r
solve_axis_direction(current, role, wanted, derive)
```

## Arguments

- current:

  Directions already declared.

- role:

  The axis with no direction yet.

- wanted:

  The value the derivation should give.

- derive:

  The derivation to invert.

## Value

A length-one named character vector.
