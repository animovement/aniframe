# Is this one of a permitted set of values?

Is this one of a permitted set of values?

## Usage

``` r
ensure_is_one_of(x, permitted, arg, call = rlang::caller_env())
```

## Arguments

- x:

  Value to test.

- permitted:

  Character vector of permitted values.

- arg:

  Name of the argument it came from.

## Value

`TRUE`, invisibly.
