# Convert radians to degrees

Convert radians to degrees

## Usage

``` r
rad_to_deg(x)
```

## Arguments

- x:

  Numeric vector of angles (radians).

## Value

Numeric vector of angles expressed in degrees.

## Examples

``` r
rad_to_deg(pi)
#> [1] 180
rad_to_deg(c(0, pi / 2, pi))
#> [1]   0  90 180
```
