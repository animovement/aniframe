# The directions an axis can point

Six words in three opposed pairs, read from where the recording was
made: `right`/`left` across the view, `up`/`down` within it, and
`back`/`forward` toward and away from the viewer. What they correspond
to in the world is `reference_frame`'s to say.

## Usage

``` r
list_axis_directions()
```

## Value

Character vector of the permitted directions.
