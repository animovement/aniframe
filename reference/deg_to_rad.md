# Convert degrees to radians

Convert degrees to radians

## Usage

``` r
deg_to_rad(x)
```

## Arguments

- x:

  Numeric vector of angles (degrees).

## Value

Numeric vector of angles expressed in radians.

## Examples

``` r
deg_to_rad(180)
#> [1] 3.141593
deg_to_rad(c(0, 90, 180))
#> [1] 0.000000 1.570796 3.141593
```
